ПРАВИЛА ЧТЕНИЯ ХРАНИЛИЩА «ЛЕТА»

1. Документы выдаются по точному имени: /files/<имя>.
2. Читатель не может выходить за пределы публичной описи docs/.
   Фильтр имён блокирует "..", "/", "\" и процент-коды. Проверено.
3. Все обращения протоколируются в базу аудита (journal).
4. Служебные файлы кода (app.py, secret_flag.py) физически лежат
   ВНЕ docs/ — в корне приложения /app. Доступ к ним невозможен.
   По крайней мере, так сказал архивариус перед увольнением.
